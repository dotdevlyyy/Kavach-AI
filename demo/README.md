# Kavach AI demo files

Synthetic, non-operational refinery inspection material for upload and extraction demos.

- `synthetic_inspection_report.docx` — editable source report
- `synthetic_inspection_report.pdf` — matching PDF for native PDF extraction
- `local_corrosion_monitoring_sop.docx` — local knowledge-base SOP
- `local_corrosion_monitoring_sop.pdf` — matching SOP PDF

Suggested prompt: `Extract findings from this report, compare them with the local SOP, and draft an approval note.`
